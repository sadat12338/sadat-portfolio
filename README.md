# Portfolio Website (React + Vite)

## Run it
1. Install Node.js (version 18 or newer).
2. Open a terminal in this folder and run: `npm install`
3. Start the site: `npm run dev` then open the link it shows (usually http://localhost:5173).

## Edit it
- Names, text, links, skills: `src/data.js`
- Colors: top of `src/styles.css` (the `:root` block)
- Put the CV in `public/` and name it `cv.pdf`

## Structure
- `src/App.jsx` joins all sections and tracks the active nav link
- `src/components/` one file per section

## Files
- CV: `public/cv.pdf`
- Photo: `public/photo.jpg`
